ROBIN CLOUD GAMING - Starter Android project

المتطلبات:
- Android Studio حديث
- JDK 17
- اتصال إنترنت عند مزامنة Gradle
- Android 10 أو أحدث للتشغيل

طريقة فتح المشروع:
1) فك ضغط الملف.
2) افتح Android Studio واختر Open ثم مجلد ROBIN_CLOUD_GAMING.
3) انتظر Gradle Sync.
4) من Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
5) ستجد APK عادةً داخل app/build/outputs/apk/debug/.

ملاحظات:
- minSdk 29 = Android 10.
- هذا إصدار أولي لواجهة منصة تجمع روابط خدمات اللعب السحابي.
- أزرار الخدمات تفتح المواقع الرسمية في المتصفح؛ لا توفر اللعبة أو الاشتراك بنفسها.
- الألعاب السحابية تعتمد على توفر الخدمة في بلدك، الحساب، الاشتراك/ملكية الألعاب، والإنترنت.
- بطاقات الألعاب في الواجهة تصنيفات توضيحية وليست ألعاباً مضمنة.
- لا يحتوي المشروع على ROMs أو ملفات ألعاب أو محتوى مقرصن.
